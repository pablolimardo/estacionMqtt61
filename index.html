1 ¿Qué es lo que tenemos?

En el laboratorio hay un dispositivo MXChip AZ3166 midiendo temperatura y humedad. Envía sus datos a un servidor central usando el protocolo MQTT. Tu trabajo es construir un SCADA en Python con Flet que muestre esa información en tiempo real.

Protocolo liviano de mensajería publish/subscribe, ideal para IoT y sistemas SCADA.

Una aplicación Python con Flet que se suscribe a los topics y muestra los datos en pantalla.

2 El Broker MQTT

El broker es el servidor que recibe los mensajes de los sensores y los distribuye a todos los clientes suscritos. Para conectarte necesitás estos datos:

Parámetro Valor Descripción
Host 10.0.14.196 IP del servidor en la red del laboratorio
Puerto 1883 Puerto estándar MQTT (sin TLS)
Autenticación Sin contraseña Acceso anónimo habilitado
Red WiFi Estudiantes Debés estar conectado a esta red
⚠️

El broker solo es accesible desde la red del laboratorio. Tu notebook debe estar conectada al mismo WiFi que los dispositivos.

3 Topics disponibles

En MQTT, los datos se publican en topics (canales). Cada sensor publica en su propio topic. Podés suscribirte a uno o a varios al mismo tiempo.

Topic Dispositivo Formato Ejemplo
estacion2/temperatura MXChip AZ3166 Número decimal 23.6
estacion2/humedad MXChip AZ3166 Número decimal 40.4
estacion2/led MXChip AZ3166 Texto red / green / blue / off
💡

Podés usar el wildcard estacion2/# para suscribirte a temperatura, humedad y led de una sola vez, en lugar de suscribirte topic por topic.

5 Conectarse al broker

Antes de construir el SCADA completo, entendé cómo funciona la conexión MQTT en Python. Este es el código mínimo para recibir datos:

Ejemplo básico — solo consola

python — mqtt_test.py 
import paho.mqtt.client as mqtt

BROKER = "10.0.14.196"
PUERTO = 1883

# paho-mqtt 2.x requiere especificar la versión del callback API
def on_connect(client, userdata, flags, reason_code, properties):
    if reason_code == 0:
        print("Conectado al broker!")
        client.subscribe("estacion2/#")
    else:
        print(f"Error de conexión: {reason_code}")

def on_message(client, userdata, msg):
    topic   = msg.topic
    payload = msg.payload.decode("utf-8")
    print(f"[{topic}] → {payload}")

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.on_connect = on_connect
client.on_message = on_message

client.connect(BROKER, PUERTO)
client.loop_forever()
⚠️

En paho-mqtt 2.x el callback on_connect recibe 5 parámetros (agrega reason_code y properties), y el cliente se crea con mqtt.CallbackAPIVersion.VERSION2. La versión 1 está deprecada.

💡

on_connect y on_message son callbacks: funciones que paho-mqtt llama automáticamente cuando ocurre un evento. Vos solo definís qué hacer en cada caso.

6 SCADA completo con Flet

El desafío de integrar MQTT con Flet es que son dos loops en hilos distintos: el loop de MQTT corre en background y necesita actualizar la UI de Flet de forma segura. La solución es usar page.run_task() con una corrutina async.

⚠️

En Flet 0.85+ llamar page.update() directamente desde un hilo externo (como el callback de MQTT) no actualiza la UI. Hay que usar page.run_task() pasándole una función async.

Código completo del SCADA

python — main.py 
import flet as ft
import paho.mqtt.client as mqtt

BROKER = "10.0.14.196"
PUERTO = 1883

# main debe ser async para poder usar page.run_task()
async def main(page: ft.Page):
    page.title   = "SCADA — Estación Meteorológica"
    page.bgcolor = "#0f1117"
    page.padding = 30

    lbl_temp   = ft.Text("-- °C", size=48, weight=ft.FontWeight.BOLD, color="#4f8ef7")
    lbl_hum    = ft.Text("-- %",  size=48, weight=ft.FontWeight.BOLD, color="#34d399")
    lbl_estado = ft.Text("Conectando...", color="#94a3b8", size=13)

    # Función async que page.run_task() puede ejecutar de forma segura desde el hilo de MQTT
    async def do_update():
        page.update()

    def on_connect(c, userdata, flags, reason_code, properties):
        if reason_code == 0:
            lbl_estado.value = "✅ Conectado al broker MQTT"
            c.subscribe("estacion2/#")
        else:
            lbl_estado.value = f"❌ Error de conexión (código {reason_code})"
        page.run_task(do_update)

    def on_message(c, userdata, msg):
        topic   = msg.topic
        payload = msg.payload.decode("utf-8")

        if   topic == "estacion2/temperatura": lbl_temp.value = f"{payload} °C"
        elif topic == "estacion2/humedad":     lbl_hum.value  = f"{payload} %"

        page.run_task(do_update)  # ← seguro desde hilos externos

    client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
    client.on_connect = on_connect
    client.on_message = on_message
    client.connect(BROKER, PUERTO)
    client.loop_start()

    # set_led debe estar dentro de main() para acceder a client
    def set_led(color):
        client.publish("estacion2/led", color)

    page.add(
        ft.Text("Estación Meteorológica", size=28, weight=ft.FontWeight.BOLD, color="#e2e8f0"),
        lbl_estado,
        ft.Container(
            content=ft.Column([
                ft.Text("MXChip AZ3166", size=16, weight=ft.FontWeight.W_600, color="#94a3b8"),
                ft.Divider(color="#2d3348"),
                ft.Row([ft.Text("🌡️ Temperatura:", color="#94a3b8"), lbl_temp]),
                ft.Row([ft.Text("💧 Humedad:    ", color="#94a3b8"), lbl_hum]),
            ]),
            bgcolor="#1a1d27",
            border_radius=12,
            padding=24,
            border=ft.Border.all(1, "#2d3348"),  # ft.Border con B mayúscula en Flet 0.85+
        ),
        ft.Row([
            ft.ElevatedButton("🔴 Rojo",   on_click=lambda _: set_led("red"),   bgcolor="#f87171", color="white"),
            ft.ElevatedButton("🟢 Verde",  on_click=lambda _: set_led("green"), bgcolor="#34d399", color="white"),
            ft.ElevatedButton("🔵 Azul",   on_click=lambda _: set_led("blue"),  bgcolor="#4f8ef7", color="white"),
            ft.ElevatedButton("⬛ Apagar", on_click=lambda _: set_led("off"),   bgcolor="#374151", color="white"),
        ]),
    )

ft.run(main)  # ft.run() reemplaza a ft.app() en Flet 0.80+
⚠️

Error común: definir set_led y los botones fuera de main() hace que client no esté en su scope. Tanto set_led como los botones deben estar dentro de main(), después de crear el cliente.

💡

¿Por qué async? page.run_task() requiere una corrutina (async def). Internamente usa asyncio.run_coroutine_threadsafe() para ejecutarla en el event loop de Flet de forma segura desde el hilo de MQTT.

Cambios importantes respecto a versiones anteriores

API antigua (deprecada) API correcta (Flet 0.85 / paho 2.x)
ft.app(target=main) ft.run(main)
ft.border.all(1, "#color") ft.Border.all(1, "#color")
mqtt.Client() mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
on_connect(client, userdata, flags, rc) on_connect(client, userdata, flags, reason_code, properties)
page.update() desde hilo page.run_task(corrutina_async)

7 Desafíos

Una vez que tengas el SCADA base funcionando, podés agregar estas funcionalidades:

Fácil

Indicador visual de estado

Cambiá el color del texto o fondo de la tarjeta si la temperatura supera un umbral (ej: rojo si > 28°C).

Fácil

Control del LED

Agregá botones en la UI para cambiar el color del LED RGB de cada dispositivo enviando mensajes MQTT.

Medio

Historial de lecturas

Guardá las últimas N lecturas en una lista y mostralas como un log o tabla en la interfaz.

Medio

Timestamp de última lectura

Mostrá cuándo fue la última vez que se recibió un dato de cada estación usando datetime.now().

Medio

Alertas sonoras o visuales

Disparar una alerta (popup, cambio de color, parpadeo) cuando un valor sale de rango normal.

Difícil

Gráfico en tiempo real

Usando flet con LineChart o integrando matplotlib, mostrá la evolución de la temperatura en el tiempo.
